Zadanie 6 - Teoria: Okienka, konwersja i zmienne

1) Rodzaje okienek:

  • Okienko alert – wyświetla okienko dialogowe z informacją i przyciskiem OK.
  • Okienko prompt – generuje okno, w którym użytkownik może wpisać wartość, zwracaną następnie do programu.
  • Okienko confirm – służy do tego, aby użytkownik coś potwierdził (zwraca wartość logiczną true lub false).

2) Konwersja zmiennych:

Wczytanie zmiennej z użyciem prompt wykonywane jest jako ciąg znaków (String), dlatego konieczna jest konwersja z ciągu znaków na wartości liczbowe, aby wykonywać obliczenia:

  • parseFloat(zmienna) - konwersja zmiennej do typu float (zmiennoprzecinkowego)
  • parseInt(zmienna) - konwersja zmiennej do typu int (liczbowego całkowitego)
  • toString(zmienna) - konwersja zmiennej do typu łańcuchowego (tekstowego)

3) Zasady nadawania nazw zmiennym:

  1. Nazwa zmiennej musi się zaczynać od litery, znaku "$" lub "_". Może zawierać tylko litery (bez polskich znaków), cyfry oraz "$" i "_".
  2. Wielkość liter ma znaczenie (np. Rekord i rekord to dwie różne zmienne).
  3. Należy nie używać słów kluczowych JavaScript jako nazw zmiennych.

4) Typy zmiennych w JavaScript:

  • Number – typ liczbowy (zmienne całkowite oraz zmiennoprzecinkowe)
  • String – typ tekstowy
  • Boolean – typ logiczny (true / false)
  • Null – pusta zawartość
  • Undefined – typ niezidentyfikowany
  • Object – obiekt
